# 复现说明

## 三种运行层次

1. `python tools/reproduce.py --mode smoke`：单元测试，约数秒；重新拟合一个基本网络以检查学习开关、准备期门控、回传路径及感觉反馈前信息隔离。
2. `python tools/reproduce.py --mode verify`：单元测试＋发布数据核对；重放原20个检查点和调优25个检查点的250次探测，重算选择、均值及逐种子差值。
3. `python tools/reproduce.py --mode full`：全部重新拟合、原四组实验、粗搜／扩域／细搜及验证；在`reproduced/`保存新数据，随后自动核对新旧结果并生成SVG。运行时间由机器决定，通常数分钟量级；不设固定耗时保证。

## 环境

运行只需标准库和NumPy 2.3.5。默认模型尺寸为64个RNN单元及48个小脑样特征，十个初始化均固定。推荐Python≥3.11。脚本在NumPy导入前将常见BLAS线程数设为1，以降低过度并行与数值漂移；单元测试也按此顺序导入。

PNG是已经导出的阅读产物，完整仿真和SVG生成不依赖Node.js。可选PNG重渲染使用仓库本地的sharp依赖；它读取相对目录，不依赖原作者电脑的运行时路径。中文字体在不同系统上可能不同，不影响CSV与模型计算。

## 固定与更新的区别

调参初始化11、22、33、44、55，验证初始化66、77、88、99、110。验证时固定两处学习系数和任务协议，但模型仍逐试次更新允许学习的权重。学习后的探测才冻结两处权重。

完整模式带`--retrain-pretraining`，忽略已有基本网络缓存，重新拟合十个初始化。原四组数据也从头计算。若直接运行调参脚本而不带该选项，它可复用已发布的预训练检查点，这会节省运行时间；两条路径应给出数值一致的基本控制器。

搜索综合目标、行为门槛与训练阶段扩域修订均在`protocol.json`记录。原始五种子搜索记录和五种子验证记录齐全。29个Pareto候选是四个误差指标下的非支配点，用于描述权衡，未据验证结果重新选择。

## 校验与容差

自动校验检查：

- 调参与验证种子分离，系数由训练记录选出且验证期间不变。
- 同种子各条件共享基本网络；仅开启的读出权重更新。
- 准备期身体静止；小脑只回传皮层输入，无直接身体输出。
- 延迟反馈到达前，没有使用真实旋转角或未来观测。
- 探测期权重保持固定，检查点能重放。
- 逐种子绝对角误差和配对差值计算正确。
- 全部轨迹与参数数值有限。

不同数值库不保证二进制逐位一致。发布数据比较采用1e-6的数值容差，基本读出重训回放采用1e-7容差；搜索选择的系数也单独核对。如超出容差，命令以非零状态退出并报告差异，不自动用新值替换发布结论。

## 目录

程序入口始终相对于自身文件解析模型目录，因此可移动整个仓库或从其他当前目录运行。使用仓库根目录命令最清晰。输出与参考数据分开：`experiments/`含发布参考，`reproduced/`含重跑产物。

本包没有论文原图或身份信息；私人课程报告与提交配图在仓库之外维护。
