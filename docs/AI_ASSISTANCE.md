# AI辅助与作者责任

本实验使用AI辅助梳理文献、提出功能性模型、编写与整理代码、设计图表及检查结果。Astra辅助审查了两系数搜索的目标、验证隔离、数值筛查、干预解释与结论边界。

研究问题及展示需求由作者提出并在讨论中持续修正。模型包含人为指定的模块、固定误差投影、归一化规则及筛查门槛；AI辅助不构成这些假设的生物学验证。

公开数据来自实际运行的仿真。仓库提供自动检查以重放检查点、重算统计、验证系数在独立初始化之前选择，以及检查输出路径和反馈前信息隔离。自动检查属于模型内部验证，不能替代对生物机制或原论文的独立实验复现。

作者在提交或发布前应理解并确认代码、评价目标和结果解释，并按课程要求说明AI使用范围。读者应将本仓库视为AI辅助完成的教学性实际尝试，而非已经发表的神经科学研究。
